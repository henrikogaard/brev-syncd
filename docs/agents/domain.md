# Domain documentation

`brev-syncd` is a single bounded context. Its canonical ubiquitous language is
the root [`CONTEXT.md`](../../CONTEXT.md).

Update that glossary when a product or protocol term becomes settled. Keep it
free of wire-format and implementation detail.

Use `docs/adr/` only for a decision that is hard to reverse, surprising without
context, and the result of a real trade-off. Protocol decision details remain
in the Phase 0 map and `docs/PROTOCOL.md` until they meet that threshold.
