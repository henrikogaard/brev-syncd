# Triage labels

Use these labels for incoming issues. Preserve their meaning; do not introduce
synonyms.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Scope, reproducibility, ownership, or priority is not yet classified. |
| `needs-info` | A specific fact from the reporter or maintainer is required. |
| `ready-for-agent` | The scope is clear and can be worked without a human decision. |
| `ready-for-human` | The next action is an explicit maintainer or product decision. |
| `wontfix` | The work is intentionally not planned. |

Wayfinder maps also use these planning labels:

| Label | Meaning |
| --- | --- |
| `wayfinder:map` | The single index issue for a planning effort. |
| `wayfinder:research` | An agent-only investigation that resolves a decision fact. |
| `wayfinder:prototype` | A human-reviewed concrete artifact used to make a decision. |
| `wayfinder:grilling` | A human-in-the-loop decision conversation. |
| `wayfinder:task` | Manual work that unblocks a decision. |
